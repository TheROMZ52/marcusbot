# MarcusBot

مارکوس یک رفیق هوش مصنوعی برای گروه‌های تلگرام و روبیکاست؛ با گفت‌وگوی خودمونی، حافظهٔ قابل‌کنترل و پاسخ‌گویی با OpenRouter.

## وضعیت فعلی

- هستهٔ Python و اتصال تلگرام: نسخهٔ اولیه
- ذخیرهٔ تاریخچهٔ محدود گفتگو در SQLite
- تنظیمات امن از طریق فایل محیطی `.env`
- اتصال روبیکا: هنوز نیازمند پیاده‌سازی و آزمایش با API/کتابخانهٔ مورد تأیید شماست؛ فعلاً فعال نیست.

## نیازمندی‌ها

- Python 3.11+
- توکن ربات تلگرام از BotFather
- کلید API از OpenRouter

## نصب در Termux یا ویندوز

```bash
git clone https://github.com/TheROMZ52/marcusbot.git
cd marcusbot
python -m venv .venv
```

فعال‌سازی محیط مجازی در ویندوز:

```powershell
.venv\Scripts\Activate.ps1
```

فعال‌سازی در Termux/Linux:

```bash
source .venv/bin/activate
```

نصب وابستگی‌ها و ساخت تنظیمات:

```bash
python -m pip install -r requirements.txt
```

فایل `.env.example` را به `.env` کپی کن و مقادیر زیر را وارد کن:

- `TELEGRAM_BOT_TOKEN`
- `OPENROUTER_API_KEY`
- `OPENROUTER_MODEL`

سپس اجرا:

```bash
python -m marcus
```

## نکات امنیتی

- فایل `.env` را هرگز commit یا منتشر نکن.
- توکن‌ها را در چت یا issue عمومی نفرست.
- مارکوس نباید بدون اطلاع اعضای گروه، پیام‌ها را برای حافظهٔ بلندمدت ذخیره کند.
- قابلیت حافظهٔ بلندمدت و پیوند هویت بین پلتفرم‌ها هنوز کامل نشده است.

## تنظیمات تلگرام

برای دیدن همهٔ پیام‌های گروه، ممکن است لازم باشد در BotFather تنظیمات Group Privacy را تغییر بدهی. فقط در گروه‌هایی از این قابلیت استفاده کن که اعضا از حضور و رفتار ربات خبر دارند.
